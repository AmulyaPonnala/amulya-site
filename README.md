# amulya-site

An earlier version of my founder site, from July 2026. It tells the same three-startup story (Pink Parcel, FemoraAI, Luna) from the period when I ran growth and go-to-market at FemoraAI while we were building Luna.

The current site lives at [amulyaponnala.github.io](https://amulyaponnala.github.io) ([source](https://github.com/AmulyaPonnala/AmulyaPonnala.github.io)).

## What's here

- `index.html` is the single-page site.
- `assets/luna-orb.html` is the animated Luna orb embedded in the Luna section.
- `assets/` also holds the photos used on the page.

It's static HTML and CSS with no build step. Open `index.html` in a browser to view it.
